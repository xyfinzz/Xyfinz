# 📚 TextVault

A lightweight collection of stories, quotes, greetings, captions, and other text-based content.

## ✨ Overview

TextVault is a simple repository designed to store and organize various writing materials in one place. Whether you're looking for inspirational quotes, birthday wishes, short stories, or random text ideas, this project keeps everything structured and easy to access.

## 📂 Contents

* 📖 Stories
* 💬 Quotes
* 🎉 Greetings & Wishes
* 📝 Captions
* 💡 Random Text
* 📚 More categories coming soon...

## 🎯 Goals

* Keep text collections organized.
* Make searching and reusing content easier.
* Provide a clean structure for future additions.
